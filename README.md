# HR-analitics
Полный пайплайн машинного обучения для решения двух HR‑задач:  
* прогнозирование уровня удовлетворённости сотрудников работой;
* предсказание вероятности увольнения сотрудника.

Проект ориентирован на практическое применение в HR‑аналитике и минимизацию кадровых рисков.

Реализованные этапы:
* Предобработка данных, исследовательский и корреляционный анализ;
* Подготовка данных, включая добавление новых признаков для задачи предсказания оттока сотрудников;
* Обучение и сравнение моделей;
* Интерпретируемость: анализ важности признаков.
